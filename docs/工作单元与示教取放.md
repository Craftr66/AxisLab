# 工作单元与示教取放

## 打开演示

完整解压 2.1 发布包，运行 AxisLab。点击“载入取放演示”，底部自动切到“工作单元”。示例由六轴、TCP 平行夹爪、传送带、光电、顶部相机、工件与工位构成。

点击“运行取放流程”执行一次；不必启动 WPF 或 VM。光电停带后，AxisLab 渲染一次相机图像，机器人按示教点取放。物品实际跟随夹爪，释放后保留在工位。

完成后点击“复位物料”再运行。复位恢复工程保存的物料位置，不把机器人瞬移回起点；启动前会从当前机器人姿态预检全部示教路径。保存工程会保存当前物品位置，若希望持续使用初始供料状态，请先复位再保存。

## 自己搭建

1. 添加机械臂、传送带、平行夹爪、光电、可抓取工件和相机。
2. 将夹爪父对象设为机器人、挂载坐标设为 TCP；配置局部安装姿态和捕获范围。
3. 工件放在传送带面上。默认沿传送带局部 +X 输送，尺寸决定带面范围；物品到末端会停止在端部，不会自动再生。
4. 光电检测区中心放在目标位置附近。设置检测区尺寸、要停止的传送带和要触发的相机。
5. 手动将机器人分别移到取料接近、取料、抬升、放料接近、放料、退回，逐个记录示教点。
6. 工作单元页选对应设备和六个示教点，点“生成流程并绑定光电 → 停带 / 相机”。
7. 核对动作表，应用修改，再保存工程。

光电对工件边缘产生触发，不是工件中心对准传感器中心时才触发。示教取料点应与停带后的实际夹持位置匹配，必要时调整检测区或光电位置。夹爪不会把远处工件吸到 TCP；范围外闭合只显示无工件，流程报告 GripEmpty 并停止。

## 自动生成的 13 步

1. 打开夹爪。
2. 启动传送带。
3. 等待光电上升沿。
4. 确认停带。
5. 等待光电触发图像完成。
6. 运动到取料接近点。
7. 到达取料点。
8. 闭合夹爪并确认夹持。
9. 抬升工件。
10. 运动到放料接近点。
11. 到达放料点。
12. 打开夹爪，放置物品。
13. 退回安全点。

动作表可修改名称、动作、设备/示教点、数值和超时，可增加延时或删除步骤。改完先“应用动作表”，再保存工程；未应用的输入不写入工程。

## 状态、停止与恢复

现场 I/O 显示传送带速度、光电 DI/上升沿计数、夹爪开合和是否持有工件。运行状态显示当前步骤、总步数与消息。

运行前预检点位和路径；更改机械臂几何、TCP、工件坐标或障碍物后，先重新校验相关示教点。传送带主体也参与基础碰撞检查。

“停止工作单元”、顶部停止及机器人停止会取消内部流程并停止传送带。若已夹住工件，则保持夹持；先手动恢复或复位物料，再重新运行。光电始终未到、图像失败、抓空、碰撞、超时或控制权丢失都会显示明确错误。

当前动作是理想运动学仿真，不模拟摩擦、输送惯性、掉落和夹持力。单循环结束不会自动生成下一件物品。VM 图像处理结果尚未作为此示教流程的运动依据。

## 相机与标定

相机页可单独预览并保存 PNG。标定时可直接在 VM 中抓图、检测特征，并在 AxisLab 移动机器人和记录示教点。“导出标定观测”输出同一曝光的图像身份、机器人关节、法兰/TCP 位姿矩阵；它不包含相机真值或内参。

固定相机 N 点标定需明确物理点与机器人 TCP/靶标原点关系；手上相机手眼标定需采集多个不同姿态。求解、坐标转换和独立误差验证在 VM 中完成，不依赖 WPF。
