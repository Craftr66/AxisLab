# AxisLab 后续开发大纲

主体始终为 AxisLab，外部 WPF/C#/PLC 均为可选客户端。当前 2.1 已实现机械臂、传送带、夹爪、光电、示教取放动作表、Modbus I/O、AxisLab 内相机发布和独立 VM 直采入口。

| 阶段 | 目标 | 验收方式 |
| --- | --- | --- |
| 2.1 当前 | 单工件光电停带、实际曝光、示教取放、自主设备逻辑 | 无 WPF 完整运行；I/O 经 Modbus 可读写；实际图像与曝光身份一致 |
| 2.2 视觉抓放闭环 | VM 输出 X/Y/角度，经 Modbus 回传视觉结果；AxisLab 内 WaitVision/MoveVision 动作、请求与曝光匹配、NG 处理 | 更换物品位置/角度后正确抓取；旧帧、重复结果、超时不执行 |
| 2.3 设备逻辑增强 | 分支、循环、单步/暂停、可配置 I/O 触发器、信号监视与故障复位 | 用户在 AxisLab 自己组合流程，保存并复现设备行为 |
| 2.4 多工件/工位 | 物料生成、输送排队、间距、多个工位、工位标识和占用、连续节拍 | 连续抓放多个工件，异常工件有明确处理 |
| 2.5 标定练习工作台 | AxisLab 内采样规划、曝光数据集、空间姿态采样、VM 标定文件/结果记录、独立误差复盘 | 仍由 VM 求解，使用独立点验证；无需 WPF 采样助手 |
| 2.6 相机与物理扩展 | 多路同时 GigE、畸变/噪声、输送惯性、夹持接触、掉落等 | 按具体场景独立验证时序、精度和兼容性 |

不恢复旧积木编辑器。现有动作表是第一版可配置设备逻辑，后续界面根据实际使用反馈设计。所有阶段应分别标明示教驱动与视觉驱动、理想运动学与物理仿真，避免把未验收能力写成已完成。
