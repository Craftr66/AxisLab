# AxisLab 2.1.0 验收记录

日期：2026-10-23，Windows x64。主体为 AxisLab，默认构建和发布均不包含 WPF Demo，也不加载 VisionMaster SDK。

## 本轮完成

- 可添加传送带、平行夹爪、光电传感器、可抓取工件；可设置速度、尺寸、夹持范围和光电停带/拍照绑定。
- 六个示教点生成 13 步设备动作表，AxisLab 自己执行输送、光电等待、停带、曝光等待、抓取、搬运、释放与退回。
- 工件实际沿带移动、随夹爪刚性运动，释放后保留世界位姿；空夹不生成工件，不把工件瞬移到夹爪。
- Modbus 暴露仪器 I/O、光电上升沿计数和流程状态，支持传送带、夹爪、内部流程启动/停止；外部带控制者断开或心跳过期会停带。
- AxisLab 自己发布虚拟 GigE，相机支持 Software 及模拟 Line0；曝光图像、HTTP PNG 与 GVSP 发送记录可对应到同一个 frameId。
- 标定观测导出包含曝光机器人姿态和图像身份，排除相机安装真值与内参，方便用户在 VM 自己求解。

## 验收边界

新 Line0 使用隔离端口的协议接收端联调，未操作使用者当前 VM 方案。此前 VM 4.3 已验证 Software 采图；Line0 仍需按实际 VM 图像源配置做本机联调。

本版为单工件、单循环的理想运动学仿真。夹爪没有接触动力学，光电采用检测体积近似；不是电气硬触发、工业安全控制器或完整物理仿真。内部示教取放尚不消费 VM 定位结果；该闭环已列为 2.2 阶段目标。
