# 当前需求确认：AxisLab 是主体

确认日期：2026-10-23。本次澄清后的分工以本文为准，替代 2.0 中由 WPF 承担主体设备流程的安排。

1. AxisLab 是机械臂工作单元仿真应用，自身添加和运行机械臂、夹爪、传送带、光电传感器、工件和模拟相机。
2. 设备逻辑、触发绑定、示教记录和取放流程在 AxisLab 内执行；不依赖 WPF 做流程调度。
3. AxisLab 模拟仪器通过 Modbus 与外部通信，既能读取光电状态，也能控制传送带、夹爪和机械臂。
4. 模拟光电上升沿可在 AxisLab 内停带并触发相机；相机向 VM 提供对应真实仿真曝光的图像。
5. 相机由 AxisLab 自己发布为虚拟 GigE，VM 直接采图、编辑视觉流程和调试标定，无需 WPF 送图或 SDK 工作进程。
6. VM 负责视觉算法与标定求解。AxisLab 提供可运动设备、图像及曝光姿态；C#、PLC、VM 或 WPF 都只是可选外部客户端。
7. 第一案例为光电停带、拍照、示教抓取、放置工位。示教点驱动的流程与未来视觉定位驱动的流程分别验收，不能把前者称为已实现视觉引导。
8. 保留场景拖拽、设备添加、尺寸配置、手动控制、示教与外部接口；旧积木编辑器继续移除。

当前交付范围：单工件单循环、理想传送带、平行夹爪刚性夹持、光电检测体积与上升沿、真实渲染图像、动作表、Modbus I/O、AxisLab 内虚拟相机管理。多工件排队、完整动力学、多路同时 GigE 和内部视觉结果握手另行扩展。
