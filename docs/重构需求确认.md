# AxisLab 统一项目需求确认

确认日期：2026-10-22。公开仓库：`Craftr66/AxisLab`。

用户已确认：

1. 删除仿真器的积木编辑器、程序执行器及相关 HTTP 接口、依赖、示例；保留场景编辑、三轴／六轴、手动控制、示教记录和示教回放。
2. 删除 WPF SDK 送图／加载方案／运行算法模式及其工作进程。视觉算法的采图、检测、标定求解和坐标转换统一在 VisionMaster 内完成。
3. WPF 负责机器人采样动作、同一曝光时的机器人姿态记录、通信、结果检查、预检及设备控制。WPF 不求解视觉标定矩阵，不把像素换算成机械臂坐标。
4. 主链路：AxisLab 虚拟相机 → VM 直接采图／运行用户流程 → VM 输出机器人基坐标目标 → WPF 校验并经 Modbus 控制 AxisLab。
5. 统一源码仓库、构建／测试入口、说明文档、发布包和启动入口；仿真器与 WPF 保持两个应用。
6. GitHub 新建公开仓库 `Craftr66/AxisLab`；源码可构建，便携应用作为 Release 附件分发。开发缓存、历史备份、个人工程及厂商 SDK／授权不进入公开仓库。

界面目标：WPF 使用“相机与通信、采样助手、结果与执行”，每页说明输入、输出和操作顺序。移除旧“VisionMaster、标定定位、九点采样、平面定位、工件方向”的 SDK 入口，保留必要能力并按新分工重做。

标定样本导出包含实际图像、帧身份、曝光机器人关节与法兰／TCP 位姿。相机安装／内参真值不进入标定样本。九点助手只执行采样动作并收集配对数据，求解和坐标转换仍由用户在 VM 中完成。

发布范围以测试与实际结果为准：完整空间手眼、多个虚拟相机同时枚举、传送带、光电、夹爪与自动抓放仍属后续能力；本次不把这些功能视作已经交付。
