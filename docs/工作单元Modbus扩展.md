# Modbus v1 扩展级别 2：仪器与工作单元

2.1 保留旧寄存器布局、功能码 03/06/16、Unit ID 1、零基 PDU 和 Float32 ABCD。寄存器 2 为 0x0201，123 为扩展级别 2。

## 设备类型与状态

新增类型 30=传送带、31=夹爪、32=光电、33=可抓取工件。目录仍在 128—191，每页 16 行；200 选择设备编号，201 选择目录页。配置能力 bit0；仪器新增 bit10=数字输入、bit11=数字输出。

仅当所选设备为仪器时，下列地址使用仪器含义。相机仍使用旧版内参/分辨率含义。

| PDU 地址 | 类型 | 含义 |
| --- | --- | --- |
| 108 | UInt16 | bit0 传送带运行，bit1 光电 DI，bit2 夹爪闭合，bit3 有关联工件 |
| 109 | UInt16 | 保留 |
| 110—111 | UInt32 | 光电上升沿计数 |
| 112—113 | Float32 | 传送带实际设定速度，mm/s |
| 114 | UInt16 | 关联工件设备编号，无则 0 |
| 124 | UInt16，全局 | 0 待机、1 运行、2 完成、3 取消、4 故障 |
| 125 / 126 | UInt16，全局 | 当前步骤 / 总步骤 |
| 127 | UInt16，全局 | 流程错误码 |

仪器的 DI 是仿真物品遮挡产生的只读信号，不能通过写寄存器强制改变。相机与机械臂原字段不改，读取前先判断设备类型。

## 新增命令

仍先将 202—229 的 28 个寄存器作为一个命令暂存区写入，再用 FC16 精确写 232—233 的新 UInt32 序号提交。会话字段 220—223、配置修订 224—225 必须匹配。未使用字段为零，204 轴数字段为 0。

| 202 操作码 | 所选设备 | 206—207，Float32 参数 |
| --- | --- | --- |
| 10 | 传送带 | 0=停止；大于 0 且不超过 1000=速度 mm/s |
| 11 | 夹爪 | 0=打开，1=闭合 |
| 12 | 取放流程对应机器人 | 不使用，零；启动 AxisLab 内部动作表 |
| 13 | 任意有效选择的设备 | 不使用，零；停止内部工作单元 |

命令 12 的完成表示“启动请求已接受”，不是全部动作完成。后续轮询 124—127 获取流程状态，不要把命令成功当成工件已放下。

外部启动的传送带需要每秒递增并写入 230—231 的心跳，5 秒未变化或连接断开会停带；夹爪保持其夹持状态，不因断线自动松开。内部流程由 AxisLab 自己维护心跳；发起启动的外部客户端离线不会代替其执行步骤。其他客户端不能在内部流程运行时抢写设备，操作员仍可停止。

错误码新增：41 CellActive、42 InvalidInstrument、43 InvalidCellSequence、44 CellTimeout、45 GripEmpty、46 CellCancelled。旧错误码和机器人指令保持。

## C# 示例

samples/ModbusClient 无第三方 NuGet 依赖，支持 io、conveyor、grip、cell-start、cell-stop。HTTP 地址用于发现实际 Modbus 端口及查询详情；仪器命令与状态仍走 Modbus。

- io 4：读取演示光电状态。
- conveyor 2 80 5：以 80 mm/s 运转 5 秒，期间维护心跳，结束停止。
- grip 5 open / close：开合演示夹爪。
- cell-start 1：启动内部流程，不接管后续步骤。
- cell-stop 1：停止内部流程。

完整机器可读映射：GET /api/v1/communication/map。
